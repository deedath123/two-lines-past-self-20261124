This entry for the make.fun bounty [Two Lines to Your Past Self](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca) warns the past self not to send a late-night text that would end a relationship with Maya, and explains why it mattered: she never read those words, and three years later she was the one holding the narrator's hand when his father died.

## Run

```sh
python3 main.py
```

This writes exactly two lines (211 characters, no trailing newline) to `/output/entry.txt`. Set `OUTPUT_DIR` to change the output directory.
