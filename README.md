# Two Lines to Your Past Self

A two-line warning to my past self, written for make.fun's Two Lines to Your Past Self bounty: line one warns about one specific moment — the 2:14 a.m. text to Maya that almost ended it — and line two traces what changed because the text was never sent. Run `python3 main.py` to write the entry to `/output/entry.txt`.
